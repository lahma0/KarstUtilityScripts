      Business card editor help

      Select an element in the tree or SVG to outline it. Drag it with the mouse, or use the arrow keys.
      Shift + mouse drag restricts movement vertically. Alt + mouse drag restricts movement horizontally.
      Arrow keys move by 1. Shift + Arrow moves by 10. Alt + Arrow moves by 0.1.
      Use the eye button to hide or show the selected element. The info button opens editable geometry and SVG attribute details.
      Scroll the mouse wheel over the image to zoom in or out, or use the +/− buttons. Click the zoom percentage to reset to 100%.
      Hold the space bar to change the cursor to a hand, then drag to pan around the image.
      Select a templates folder to start.
