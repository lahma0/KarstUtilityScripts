A collection of useful utilities and scripts for use within the organization. The repository will focus primarily on Microsoft 365/Azure/Entra, including scripts for user management, email security, identity management, onboarding/offboarding, Intune device management, etc. An attempt was made to organize the scripts in a categorical directory structure, but some scripts serve multiple purposes, match multiple categories, or do not fit neatly into a particular category. Over time, documentation will be added below to shortly describe the function of each script.
